Architecture

How a request moves through the system.

1
Dataset builder

Legal clause classification examples in instruction format; splits are template level so no near duplicate ever leaks from train into test.

2
Config driven training

PEFT plus TRL with QLoRA 4-bit; rank 16, alpha 32, dropout 0.05 as the documented baseline. Every run is reproducible from its YAML alone.

3
Sweep

Rank, learning rate, and epochs swept on a grid; the leaderboard drives the final configuration choice.

4
Honest evaluation

The base model scores the benchmark first; the adapter runs the identical protocol, reported with per category deltas, improvements, and regressions.

5
Forgetting check

General capability probes run on both models; a significant drop fails the run.

6
Deployment

The adapter exports at under 100 MB and serves behind an A/B comparison endpoint next to the base model.

How to use

Runs fully offline with a deterministic provider; add API keys to switch to live models.

# simulation mode runs the whole pipeline anywhere
pip install -r requirements.txt
python data/build_dataset.py
python demo.py

# real training on a GPU machine
pip install -r requirements-gpu.txt
python -m src.finetune.train --config configs/lora_r16.yaml
python -m src.finetune.train --sweep configs/sweep.yaml
